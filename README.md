# NightCare – Night-Shift Adaptive Interface

## About the Project
NightCare is an adaptive interface designed for hospital and factory night-shift workers. It helps users manage tasks, monitor fatigue, take breaks, and adjust screen settings for comfortable night-time use.

## Features
- Login page
- Dashboard with shift overview and task summaries
- Task management
- Alerts and notifications
- Fatigue support and wellbeing check-ins
- Adaptive themes: Light, Dim, Dark, and High Contrast
- Brightness and text-size controls
- Automatic theme switching

## Technologies Used
- HTML
- CSS
- JavaScript
- Figma
